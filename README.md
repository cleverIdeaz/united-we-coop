# United We Co-op

**Working idea:** a shared knowledge + fundraising network for cooperative education.

## Core mechanic

1. A verified co-op contributes something useful: a live office hour, role-specific discussion, template, or playbook.
2. United We Co-op distributes the session by topic/role so discovery can extend beyond that school's existing circle.
3. The event spotlights a concrete need at the host school.
4. Donations go **directly to that school's existing payment processor**. The platform does not pool funds.
5. The recording/resource remains accessible and keeps pointing back to the school that created it.

The pilot uses Creekside Cooperative Preschool & Kindergarten in Indianapolis.

## Why the V1 is intentionally static

There is no user authentication, wallet, or custom school-admin system yet. School profiles and events can be manually published. Registration can use the host school's existing forms/video platform. Fundraising links go straight to the school.

That is enough to validate the question that matters: **does useful shared knowledge bring new attention and new support to co-ops?**

## Working brand

The site uses **United We Co-op** / unitedwecoop.com as the working identity. "COOP Coalition" is already used by another cooperative network, so this avoids a needless naming collision while preserving the broader coalition idea.
